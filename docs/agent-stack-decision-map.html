Coding-agent stack decision map — four paths

You start with no stack and choose one option at each decision; the series of choices is your path, and every path ends at a working model + harness + git setup. Two paths are direct reads of a specific published source; one is this project's own build; one is the naive baseline those sources are explicitly reacting against, not a recommendation. Toggle a path below to trace it — where two agree, their lines run parallel; where they part, that's the actual tradeoff, not just a labeled box.

● a stated fact from that path's source. ○ a value inferred or assumed rather than directly stated — see footnotes below before relying on it. Where two paths pick the same option their lines are nudged apart so both stay visible; that's a shared choice, not a coincidence in the drawing.
